特殊需要人士游泳教師證書課程

證書課程自學教材：每單元依課堂情境、教學原則與池邊執行整理；可聽粵語說明、點選術語返回講義出處，並以選擇題與五類教案核對。

本網站根據課程講義、課堂分享與溝通工具筆記整理，供未能出席面授的學員系統研讀。不能代替醫療診斷、法律意見、課堂實習或面授扶抱示範。涉及健康、用藥、脊柱或癲癇等情況，須按家長／醫護文件執行。

自學路徑

本網站按證書課程講義重整，供未能出席面授的學員系統自學。請依專業判斷的先後次序研讀：先建立角色與安全，再處理溝通與行為，最後才編寫教案。選擇題用以核對理解，不宜作為唯一學習方法。

  1. 先依本頁建議次序研讀，勿一開始只操選擇題。
  2. 每一單元：先讀導讀，再讀重點（情境 → 原則 → 池邊執行），並聽粵語說明一次。
  3. 專用術語（TEACCH、STEP、PECS、WPW 等）可點選返回講義出處。
  4. 完成該單元練習；答錯者以「提示」回到原文覆習，再訂正概念。
  5. 對照五類教案，檢視策略欄是否具名方法、原因欄是否對應該學員。

建議先讀這幾課

  1. 1.1 認識特殊需要及本地支援系統 — 確立專業角色：尊重用語、三層支援；教師不作診斷。
  2. 1.3 特殊需要人士習泳之價值 — 理解水的特性與習泳價值；目標為適應與安全，而非根治。
  3. 4.3 特殊需要人士游泳安全指引 — 安全鏈、師生比例、水溫與不宜游泳條件；安全未備妥則不教泳式。
  4. 2.8 提昇與特殊需要學員的溝通 — PECS、圖卡與短指令；多數行為問題先檢視溝通。
  5. 2.8b 泳池提示咭與先－後卡 — 列印並過膠提示咭；學員遞卡必須即時兌現。
  6. 2.9 正向行為管理及小組教學 — 以 ABC 分析前因與功能；勿因一次哭鬧而永久取消技能。
  7. 4.4 特殊需要人士游泳教學法 — TOP SECURe 與具名策略，對齊作業五階段表。
  8. CP 保護兒童原則 — 更衣、觸碰與報告途徑；兒童安全優先於機構形象。

類別單元（2.1–2.7）按將會任教的對象選讀。扶抱（3.2、3.3）須對照示意圖，並謹記先說明再接觸。完成研讀後，可以用選擇題核對，並以五類教案為範本按當日學員改寫，切勿原文照錄。

基礎

1.1 認識特殊需要及本地支援系統

本單元確立教師的專業界線。泳池上所見，是需要額外支援的人，不是一個病名。須以尊重用語記錄可觀察行為，把康復期望帶回適應與安全；診斷與用藥屬醫護及心理學專業。

1.2 國際及香港特殊需要人士游泳運動發展

開班前須分清興趣泳班與泳隊。兩者目標、訓練量與成功準則不同。完成、自信與參與，同樣構成有意義的成功經驗；勿以競賽標準衡量初學。

1.3 特殊需要人士習泳之價值

浮力、靜水壓與阻力，解釋為何部分學員陸上困難、水中較易起步。教學重點是承托、感覺整理與可觀察的小進步，不是保證成為泳手。

類別

2.1 肢體、視覺、聽力障礙

肢體、視覺、聽覺障礙的池邊安排不同：由優勢側出發、固定動線、面對面與視覺緊急信號。輔具多數不防水。有癲癇史須課前預案；抽搐期間不宜強拉。

2.2 智障及多重障礙

智力障礙須同時評估智力功能與適應行為。長指令容易漏步，宜拆短、配圖、工序分析。師生比例按程度收緊：嚴重約 1:1、中度約 1:5、輕度約 1:10。

2.3 唐氏綜合症

唐氏綜合症常見肌張力低、關節較鬆、心肺耐力不足。課前核對心臟與頸椎文件；醫護提示寰樞椎不穩時，禁止跳水、滾翻與過度頸伸。

2.4 感覺統合障礙

感覺統合困難不是「不聽話」。先判斷當下是觸覺、前庭還是本體覺過多或不足，再決定減刺激或提供安全的替代輸入。摀耳、逃避花灑，宜先減少輸入。

2.5 注意力不足及過度活躍症

課堂宜拆成短循環，一次一個指令；等待時給予可完成的小任務。利用水阻力使動作變慢，練習抑制控制。衝動風險高者遠離跳台。教師不作診斷、不建議藥物。

2.6 自閉症譜系障礙

以 TEACCH 視覺結構化降低未知。入水採看→接觸→部分浸入；恐慌即退回上一階段，禁止推落水。游泳協助適應與安全，不能根治自閉症。

2.7 特殊學習困難和常見精神病

讀寫困難不代表泳術較差，但池邊不宜只貼長文。情緒低落、過度道歉或突然疲憊，須記錄並告知監護人；不公開診斷、不自行改藥。

U-list 常見障礙與教學備註

編寫教案時，勿複製病名清單。須把評估消化為該學員在更衣室、入水、聽指令時的具體需要，並只填寫已核實的醫療限制。

教學支援

2.8 提昇與特殊需要學員的溝通

溝通是全課程的核心能力。須能說明 PECS 所處階段、水中防水卡套裝，以及岸上如何與匡智溝通易或 GoTalk NOW 對齊。指令宜短，並請學員覆述。

2.9 正向行為管理及小組教學

行為是學習的結果，也傳遞需要。以 ABC 記錄前因、可觀察行為與後果。優先調整環境、教導替代溝通，並給予即時具體讚賞，而非僅處罰或永久取消技能。

2.8b 泳池提示咭與先－後卡

圖卡須列印、過膠並扣於池邊。學員遞出「停／害怕／幫忙」必須即時兌現。先－後卡用以預告：先完成指定小步，再給予休息或選擇。

實務

3.2 陸上扶抱特殊需要人士技巧

陸上轉移：能走則少抱；接觸前先說明；承托軀幹並保護頭頸；地面須防滑。觸碰應可見、必要、可解釋，避免關閉的一對一空間。

3.3 水中扶抱與協助

水中教師須站穩可點地區，學員口鼻離水。仰浮承托頭與肩。協助由全抱→輕觸→獨立遞減。若學員突然攬頸，先穩氣道、轉位並呼叫，勿對罵或下沉掙扎。

4.2 特殊需要人士游泳教學經驗分享

教案須寫得出、可修訂、含危機處理。興趣班以愉快循序為先；泳隊才進入專項。教師與助理口令須一致；任何時候學員都應處於安全環境。

4.3 特殊需要人士游泳安全指引

安全由更衣室開始，交回指定接送人才算完課。文件未齊不下水。須掌握比例、不宜游泳例子，以及初學水溫約 28–32°C。發紺、打顫即上水。

4.4 特殊需要人士游泳教學法

作業須寫五階段：熱身、主題、遊戲、緩和、課後延伸。每一格策略欄具名 TEACCH、STEP、WPW 等方法；原因欄解釋為何適合該學員。此為編寫作業的關鍵單元。

4.5 特殊需要人士體適能測試及相關運動研究

評估用以分組與訂立可完成目標，不是公開排名。文獻數字僅為參考區間；個人強度仍須按當日身體狀況調整。

4.6 特殊需要人士游泳教師法律指引概要

合理謹慎不是保證零意外，而是按訓練與已知病歷採取預防。知情同意須書面。不能診斷、不能承諾包學成、不能超收至視線不及。事故須記錄上報。

CP 保護兒童原則

兒童安全優先於機構形象。懷疑傷害須按指定途徑報告，不承諾保密、不自行審問。更衣與扶抱須透明；害怕卡必須兌現。
