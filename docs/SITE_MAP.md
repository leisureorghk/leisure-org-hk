# 公開頁分類地圖

所有下列檔案皆在**倉庫根目錄**（或註明之資料夾）；網址為 `https://www.leisure.org.hk/<檔名>`。

## 行銷／機構

- `index.html` — 首頁
- `about.html` — 關於我們
- `services.html` — 服務項目
- `why-us.html` — 為何選擇我們
- `booking.html` — 預約課程
- `contact.html` — 聯絡我們
- `areas-hong-kong.html` — 服務地區

## 家長資源（入門）

- `resources.html` — 家長資源總覽（認識 SEN＋幫助孩子）
- `sen-guide.html`、`sen-support-hk.html`
- `sen-swim-first-lesson.html`、`sen-swim-benefits.html`、`sen-swim-safety.html`
- `sen-swim-autism.html`、`sen-swim-adhd.html`
- 下載頁：`download-*.html`

## 深入內容（登入碼限制）

以下根目錄頁有全文，並以 `js/coach-gate.js` 要求登入碼；未登入會導向 `coach-share.html`：

`sen-swim-learning`、`down-syndrome`、`intellectual`、`physical`、`sensory`、`communication`、`behavior`、`classroom`、`wellbeing`、`development`

備份：`private/coach-html/`（不部署）。`Learn/` **不部署**到 Pages。

說明見 [`COACH_ACCESS.md`](./COACH_ACCESS.md)。
